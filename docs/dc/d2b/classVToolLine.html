◆ isUsedInFormula()

bool VToolLine::isUsedInFormula ( ) const

isUsedInFormula check if the length or the angle of this line is used in a formula.

A line has no object in the data container, only the length and angle variables the tool registers with VContainer::AddLine(). Those variables are referenced by name, so the id based reference counter never sees them and can't stop the line from being deleted while a formula still needs it.

Returns
true if a formula references the length or the angle of this line.
