◆ adaptColor()

QColor adaptColor ( const QColor &  color)

adaptColor color to show on the drawing area.

On a dark background (and with "Adapt colors to a dark background" on) black is shown as light grey so it stays visible. Every other color is painted exactly as it was chosen, so the drawing area always matches the color picker. This is the same idea as AutoCAD's black/white color, which draws white on a dark model space and prints black. Display only: the pattern keeps the real color for saving, printing and export.

Parameters
colorthe color stored in the pattern or settings.
Returns
the color to paint with.
