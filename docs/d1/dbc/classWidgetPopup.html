WidgetPopup::WidgetPopup ( QWidget *  parent = nullptr)
explicit

Class showing a widget as popup window.

Parameters
parent
  • If parent not specified (default), then popup widget gets attribute Qt::WA_DeleteOnClose and will be deleted after close.
  • setParent() function allows you to specify the widget to be popped up. After widget is set, you normally should call show() slot in order to pop the widget up at the specified global position.
  • WidgetPopup takes care about positioning of your widget on the screen so it will be always visible even if popped beside.
