34/**
35 * ParentNode provides the capability of having child
36 * nodes. Not every node in the DOM can have children, so only nodes that can
37 * should include this class and pay the price for it.
38 * <P>
39 * While we have a direct reference to the first child, the last child is
40 * stored as the previous sibling of the first child. First child nodes are
41 * marked as being so, and getNextSibling hides this fact.
