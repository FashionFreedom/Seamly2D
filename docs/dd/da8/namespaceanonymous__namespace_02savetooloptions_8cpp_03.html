QString anonymous_namespace{savetooloptions.cpp}::childElements ( const QDomElement &  element)

childElements serialize the child elements of a tool element.

Some tools keep object references in child elements instead of attributes, for example the points of a spline path. Text nodes are skipped.

referencesChanged check if a tool option change replaced a referenced object.

The reference counters that guard deletion are only set when a tool is created during a full parse. When an option change replaces a referenced object the counters become stale, so the caller has to request a full parse to rebuild them. See issue #1521.
