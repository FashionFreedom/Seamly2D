◆ renderScaledDiagram()

void TMainWindow::renderScaledDiagram ( )
private

renderScaledDiagram Generates a pixel-perfect, crisp vector diagram to fit the current dock size.

Loads the active SVG file path from memory and dynamically reads the real-time dimensions of the main window's dock container. It compares horizontal and vertical scaling factors to determine the maximum aspect-ratio fit, preventing layout bleeding. The mathematical vector paths are then rendered onto a sharp, transparent canvas layout, updating the display widget alongside its text caption label.
